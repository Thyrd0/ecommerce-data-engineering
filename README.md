# E-commerce Data Engineering Pipeline

## Descripción

Proyecto personal de Ingeniería de Datos orientado a construir un pipeline ETL/ELT de extremo a extremo utilizando un conjunto de datos público de comercio electrónico.

El objetivo es integrar, transformar, almacenar y preparar datos para su análisis empresarial mediante una arquitectura Medallion.

## Objetivos

- Desarrollar procesos de ingesta de datos.
- Implementar una arquitectura Bronze, Silver y Gold.
- Construir un Data Warehouse dimensional.
- Automatizar pipelines de datos.
- Implementar controles de calidad.
- Generar información para análisis empresarial.

## Tecnologías

- Python
- PostgreSQL
- Apache Airflow
- dbt
- Docker
- SQL
- Power BI
- Git y GitHub
